# Naman Shastri - Professional Portfolio

Welcome to my interactive portfolio website! This portfolio showcases my skills, projects, experience, and expertise as an IT student and web developer.

## 🌟 Features

- **Responsive Design**: Fully responsive and mobile-friendly interface
- **Interactive Animations**: Smooth scroll animations and hover effects
- **Modern UI/UX**: Clean, professional design with gradient themes
- **Skills Showcase**: Visual representation of technical skills with progress bars
- **Project Portfolio**: Detailed project cards with descriptions and technologies
- **Experience Timeline**: Visual timeline of professional experience and education

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- No server or build tools required - pure HTML/CSS/JS

### Installation

1. Clone the repository:
```bash
git clone https://github.com/shastrinaman40/portfolio.git
cd portfolio
```

2. Open the portfolio in your browser:
```bash
# Simply double-click index.html or
open index.html
```

Or use a local server:
```bash
# Using Python 3
python -m http.server 8000

# Using Python 2
python -m SimpleHTTPServer 8000

# Using Node.js (if installed)
npx http-server
```

Then visit `http://localhost:8000` in your browser.

## 🎨 Customization

### Colors
Edit the CSS variables in `css/styles.css`:
```css
:root {
    --primary-color: #6366f1;
    --secondary-color: #8b5cf6;
    --accent-color: #ec4899;
    /* ... more colors */
}
```

### Content
Edit `index.html` to:
- Update personal information
- Add/modify projects
- Change skills and certifications
- Update contact information

### Fonts
Currently using Google Fonts "Poppins". To change:
1. Update the font-family in `css/styles.css`
2. Modify the Google Fonts import URL in `index.html`
